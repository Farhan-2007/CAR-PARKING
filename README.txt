# 🚗 ParkEasy – Car Parking Management System

ParkEasy is a simple web-based car parking management system that allows users to register, log in, view available parking slots, book a slot, make a simulated payment, and view their booking history.

The system also provides an admin dashboard to monitor the current parking slot status.

---

## ✨ Features

- User Registration and Login
- Secure session-based authentication
- View available and occupied parking slots
- Book an available parking slot
- Automatic simulated payment after booking
- View personal booking history
- Admin parking status dashboard
- Real-time slot status from the database
- Responsive and user-friendly interface

---
